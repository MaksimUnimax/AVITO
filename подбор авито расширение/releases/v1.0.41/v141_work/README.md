# Avito Finder v1.0.39

Minimal patch over exact v1.0.38. If several Avito tabs exist and none is the active browser tab, Finder may bind only when exactly one existing tab already matches the command's normalized requested public Avito route. Zero or duplicate exact matches remain terminal ambiguity. No tab is navigated merely to resolve ambiguity. Queue/cursor, proxy/recovery, capture/report and CAPTCHA boundaries are unchanged.
