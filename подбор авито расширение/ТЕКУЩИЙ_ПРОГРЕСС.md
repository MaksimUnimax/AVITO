## Root cause v1.0.40

v1.0.39 научился **переиспользовать** ровно один existing exact-requested Avito tab, но first-target allocator всё ещё завершал работу terminal ambiguity, когда существующие вкладки нельзя было безопасно выбрать однозначно.

1. unique active Avito preference сохранён;
2. unique exact requested existing-tab reuse сохранён;
3. single Avito tab reuse сохранён;
4. zero-tab bootstrap сохранён;
5. если existing candidates неоднозначны, requested URL является валидным public Avito URL, это первое user-started binding и navigation разрешён — ни одна существующая tab не угадывается и не мутируется; создаётся одна новая dedicated public Avito tab и нормальным routing path переводится на requested URL;
