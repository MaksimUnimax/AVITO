## Цель подбора

Только WORK; GAMING / UNIVERSAL / BUDGET не ведутся. Ищем готовый рабочий ПК за 8 000–15 000 ₽ включительно с подтверждённой прямой Avito Доставкой. Нагрузка: ChatGPT, много вкладок, CorelDRAW, офис, документы и многозадачность. Приоритет: CPU → RAM → SSD/NVMe → платформа, надёжность и апгрейд → GPU. Игровая видеокарта сама по себе преимуществом не считается.
