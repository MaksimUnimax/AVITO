## Что исправлено относительно v1.0.23

Первый live-запуск `компьютер / p1` на v1.0.23 показал новый путь ошибки:

`COLLECT_LISTINGS: blocked — AVITO_IP_BLOCK`

v1.0.23 умела входить в VERIFIED EGRESS recovery, когда IP-block определялся на page-readiness/main-frame этапе. Но если страница проходила readiness, а блок обнаруживался позднее внутри `COLLECT_LISTINGS`, UI-plan сразу оформлял blocked-report и recovery не запускался.

v1.0.24 добавляет точечный переход:

`collection-first UI plan detects AVITO_IP_BLOCK → VERIFY/ROTATE/VERIFY → reload only after verified recovery → replay the same collection-first plan`

Дополнительно bounded recovery counter больше не сбрасывается при повторном входе в UI-plan.

Произвольные click/type/filter планы автоматически не replay'ятся: повтор разрешён только для collection-first плана, чтобы не дублировать видимые действия.

## Сохраняется из v1.0.23

- `rotation=0 / Каждый запрос` не переключается автоматически на Sticky;
- реальный egress проверяется через tiny IP canaries;
- `change_ip_link` не является доказательством без измеренного результата;
- без подтверждённого recovery Avito не reload'ится;
- transport errors входят в тот же verified recovery;
- ZERO-MEDIA сохраняется;
- CAPTCHA остаётся ручной границей.
