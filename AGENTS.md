# Обязательный порядок работы с Avito Finder

Перед любой работой полностью прочитать:

1. `подбор авито расширение/PATCH_ENGINEERING_RULES.md`.
2. `подбор авито расширение/ТЕКУЩИЙ_ПРОГРЕСС.md`.
3. Последний checkpoint по текущей задаче. Для прерванной публикации 2026-09-12: `подбор авито расширение/CHECKPOINT_2026-09-12_PUBLICATION_RECOVERY.md` и `PUBLICATION_CURSOR_2026-09-12.json` в той же папке; затем `CHECKPOINT_2026-09-12_v1.0.35_RECHECK.md` и исходный `CHECKPOINT_2026-09-12_v1.0.35.md` как историю.

## Сохранение промежуточного результата

После каждого законченного материального блока сохранять код/тест/результат/состояние в GitHub и проверять чтением обратно. Не ждать финала длинной операции. До перехода к следующему блоку должен существовать точный указатель продолжения: подтверждённый commit, выполненные действия, оставшаяся работа, FAIL/ограничения и хеши артефактов. Нельзя оставлять единственную копию во временной среде чата.

Для передачи архивов сохранять не только число частей: фиксировать точный алгоритм/скрипт упаковки, хеш полного потока, имена, размеры и хеши частей, что действительно присутствует удалённо, и первый недостающий файл. При потере локального потока нельзя дописывать к его удалённому префиксу части другого потока.

## Обязательный отчёт при каждом патче

Вместе с патчем показывать правила и фактическое соблюдение каждого применимого пункта: PASS, FAIL, NOT_RUN или BLOCKED с доказательством. Отдельно указывать, какие правила нарушены текущим патчем и предыдущим процессом; исторические нарушения нельзя выдавать за нарушения, совершённые именно сейчас, и наоборот.

## Нельзя подменять результат

- Workflow в GitHub не означает, что архив или исходники опубликованы.
- Локальный файл не означает наличие удалённой копии.
- PASS отдельной функции не означает PASS связки компонентов.
- Архивная QA другой версии не является QA текущего ZIP.
- Блокирующий runtime FAIL нельзя переименовать в "только ограничение среды" без воспроизведения.
- Нельзя ослаблять защитные проверки ради зелёного теста.

## Текущий известный FAIL

В exact ZIP v1.0.35 manifest имеет version 1.0.35, но `avito_content.js` возвращает ADAPTER_VERSION 1.0.34. Worker намеренно требует равенства. Полные циклы воспроизвели `AVITO_ADAPTER_VERSION_MISMATCH_RELOAD_REQUIRED`. Не объявлять v1.0.35 рабочей. Сначала сохранить исходный архив как не принятый артефакт, затем минимально исправить доказанную несогласованность в новой версии и повторить весь сценарий.
